Layer 01

Client & Presentation Tier

Modular Single-Page Application (SPA) designed with pure vanilla web standards and CSS tokens.

  • Semantic HTML5 + WCAG accessible dialogs & navigation
  • Dual-theme engine (Dark & Light) with localStorage sync
  • Pure CSS 3D rotating neural visualization core
  • Web Speech API: SpeechRecognition (STT) + SpeechSynthesis (TTS)
Layer 02

ASGI Gateway & Transport

Asynchronous high-throughput server architecture unifying frontend asset delivery and REST APIs.

  • FastAPI & Uvicorn ASGI server with hot-reload
  • Strict CORS middleware supporting local and deployed origins
  • Static files mounted at root for unified deployment
  • Real-time /health probe and API versioning handshake
Layer 03

Document Ingestion Engine

High-speed in-memory document parsing and text extraction with multi-format support.

  • PyPDF2 stream parser with encrypted document detection
  • python-docx extractor with merged table cell deduplication
  • Legacy .doc binary token regex stream decoder fallback
  • 5 MB size enforcement & input sanitization boundaries
Layer 04

Cognitive AI & Fallback Tier

Dual-engine intelligence layer combining advanced generative models with deterministic heuristics.

  • Google GenAI SDK powered by Gemini 2.5 Flash
  • Structured JSON extraction schema with candidate sandboxing
  • Dynamic difficulty controller adjusting follow-up questions
  • Deterministic heuristic fallback engine ensuring 100% uptime
